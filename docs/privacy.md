# Приватность, согласия и защита данных (152-ФЗ)

## 1. Принципы

- Обработка персональных данных осуществляется только при наличии **согласия**
  пользователя (кандидата) на обработку и публикацию данных профиля.
- Кандидат управляет приватностью: решает, какие поля видны работодателю
  (настройки профиля).
- Работодатель **не видит контактные данные кандидата** до момента, когда кандидат
  принял приглашение или откликнулся сам (правило ТЗ п.2.2.2).
- Хранение паролей/токенов — только в зашифрованном виде; в MVP авторизация
  отсутствует, поэтому пароли не хранятся вовсе.

## 2. Реализация в MVP

- Поля `email` и `telegram` кандидата не обязательны при регистрации;
- В API офферов поле `candidate_telegram` возвращается, но на следующем этапе будет
  скрываться до статуса `accepted`;
- Достижения ФСП публикуются в профиле только после привязки ID ФСП самим кандидатом
  (поле `fsp_id`).

## 3. Чек-лист соответствия 152-ФЗ (для финальной версии)

- [ ] Политика обработки ПДн и форма согласия при регистрации;
- [ ] Журнал действий с ПДн (кто и когда смотрел профиль кандидата);
- [ ] Возможность отзыва согласия и удаления аккаунта;
- [ ] Шифрование токенов Keycloak (OIDC) в хранилище;
- [ ] Разграничение ролей (кандидат/работодатель/админ) на уровне API;
- [ ] Rate limiting и защита от перебора;
- [ ] Регистрация по email с подтверждением адреса.

## 4. Настройки приватности (проектируемые)

| Настройка | Описание |
| --- | --- |
| Видимость контактов | email/telegram видны только после принятия оффера |
| Видимость достижений ФСП | можно скрыть достижения из публичного профиля |
| Видимость в поиске | можно отключить показ профиля в подборках (инкогнито) |
| Согласие на публикацию | чекбокс при регистрации и в настройках |
