## Post-MVP — следующие итерации

### 1. Интеграция с реальным API ФСП
- OIDC client (Keycloak).
- Реальный `getAchievements` + кэш с TTL.
- Webhook для push-обновлений достижений.

### 2. ML-ранжирование вместо rule-based
- Заменить `scoreCandidate` моделью (XGBoost / нейросеть) на признаках:
  пересечение стека, грейд, роль, ФСП-достижения, история тестов.
- A/B-тест: model vs rule-based на `data/validation-report.json`.

### 3. Расширение банка заданий
- Добавить вопросы для `devops`, `qa`, `lead`.
- Перевод на единый YAML/JSON для удобного редактирования.

### 4. Защита от фиктивных вакансий (prod)
- Email/телефон верификация работодателя.
- ML-классификатор вакансий на спам.
- Whitelist/blacklist работодателей.

### 5. ATS-интеграции (prod)
- Greenhouse / Lever / Workday / hh ATS адаптеры.
- Подписка на события ATS (candidate hired).

### 6. UX-доработки
- Push/Telegram-бот уведомления о приглашениях и откликах.
- Канбан откликов в кабинете работодателя.
- Мобильная адаптация отдельной версии.

### 7. Аналитика и наблюдаемость
- Метрики воронки (отклик → оффер → принят).
- Дашборд для HR с временем до закрытия вакансии.
- Интеграция с Prometheus/Grafana.

### 8. Юридическое (prod)
- Полнотекстовая политика обработки ПДн.
- Версионирование согласия.
- Endpoint `/api/me/delete` для удаления аккаунта и всех связанных ПДн.
