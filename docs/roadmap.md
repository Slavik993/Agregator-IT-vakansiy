# Дорожная карта и дополнительный функционал

## 1. Роли, регистрация и личные кабинеты (следующий этап)

### 1.1 Регистрация

- Регистрация по email с подтверждением адреса (код/ссылка);
- Выбор роли: кандидат или работодатель;
- Верификация работодателя — за рамками MVP (концепция ниже).

### 1.2 Ролевые кабинеты

- **Кандидат**: профиль, тестирование, приглашения, отклики, настройки приватности,
  связь с ID ФСП;
- **Работодатель**: профиль компании, потребности, подборки, поиск, офферы, вакансии.

Разграничение доступа: кандидат видит только свои приглашения и отклики;
работодатель — только свои вакансии и офферы.

## 2. PDF-профиль и автораспознавание резюме

- Автогенерация стандартизированного PDF-профиля (серверная генерация, библиотека
  pdfkit / puppeteer);
- Загрузка PDF-резюме с автораспознаванием (ФИО, контакты, стек, грейд, роли, стаж,
  софт-скиллы): NLP-парсер (например, spaCy/Transformers для русского языка или
  rule-based извлечение) — преимущество при оценке (ТЗ 3.2).

## 3. Отклики кандидата на вакансии (+7% оценки)

Дополнительный сценарий, позволяющий кандидату проявлять инициативу:

- Таблица `applications` (candidate_id, vacancy_id, status, created_at);
- Статусы: `sent`, `viewed`, `accepted`, `declined`;
- API: POST /api/vacancies/:id/apply, GET /api/candidates/:id/applications;
- Контактные данные кандидата раскрываются работодателю после отклика.

## 4. Регулярные короткие задания (+7% оценки)

- Таблица `challenge_attempts` (candidate_id, employer_id, task, answer, status);
- Планировщик (cron) раз в 2 недели выбирает кандидатов с активным профилем;
- Работодатель может прикрепить задачу к офферу;
- Результат влияет на «актуальность» профиля: свежий сигнал повышает позицию
  в ранжировании внутри категории.

## 5. Защита от фиктивных вакансий и недобросовестных работодателей (+7%)

Концепция:

- **Верификация работодателя**: проверка домена корпоративной почты, ИНН/ОГРН через
  открытые реестры, ручная модерация первых вакансий;
- **Рейтинг надёжности**: история размещений, доля принятых офферов, жалобы кандидатов;
- **Лимиты**: новые компании публикуют ограниченное число вакансий до верификации;
- **Модерация**: автоматический фильтр (дубликаты, некорректные зарплаты,
  подозрительные формулировки) + очередь ручной проверки.

## 6. Интеграция с ATS-системами работодателей (+7%)

- Webhook-уведомления о новых офферах/откликах;
- Экспорт кандидата в формате ATS (JSON Resume / стандартные поля);
- OAuth-подключение к популярным ATS (например, через универсальный коннектор);
- REST API для импорта вакансий из ATS.

## 7. Адаптивная вёрстка (+7%)

- Мобильная версия личных кабинетов;
- Тестирование на разрешениях 360px+.

## 8. ML/LLM-улучшения

- Замена rule-based матчинга на ранжирующую модель (learning to rank);
- Генерация заданий нейросетью с калибровкой сложности (см. docs/testing.md);
- Семантический поиск по стеку и описаниям вакансий (эмбеддинги).
